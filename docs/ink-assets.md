# 水墨素材

工具：内置 Imagegen。素材：`src/assets/ink/dry-brush.png`，透明 PNG，2172 × 724。原图保留完整 alpha，未裁切、未再加工。CSS 使用 alpha mask 并按横向笔触比例显示。

最终提示词：

> Use case: stylized-concept. Asset type: transparent UI ink brush mask for a Chinese ink-on-xuan-paper Gomoku game. Create ONE horizontal black Chinese calligraphy brush stroke, centered in a landscape canvas, about 5:1 width-to-height stroke, with generous transparent padding. Authentic scanned sumi ink: heavy wet ink at the rounded left press, coarse organic bristle edge, long fine parallel dry-brush white/transparent fissures through the middle, tapering swiftly to separate needle-thin bristles on the right, and a few tiny irregular black ink splatters near both ends. Rich matte carbon-black ink, translucent feathered bleed at parts of the edge, natural uneven pressure. Flat top-down texture scan, not a rendered object. Actual fully transparent background including gaps between hairs. No text, no characters, no brushes, no paper, no shadows, no glows, no color, no rectangle or oval shape. Intended to be used as CSS mask, so silhouette and alpha detail are essential.
